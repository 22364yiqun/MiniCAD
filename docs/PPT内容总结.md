## 一、3.1 图形系统分析及图形用户界面与交互式技术

### 1. 课程主线

本课从图形系统的底层能力讲起，依次介绍图形系统的关键技术、图形交互技术、图形用户界面设计，并以 VCAD/Draw-OpenGL/QCAD 等系统作为实践背景。核心目标是理解一个 CAD 或计算机图形系统如何生成、管理、编辑和显示图形，以及如何让用户高效地与系统交互。

### 2. 图形系统的关键技术

#### 2.1 基本图形生成

系统需要支持直线、圆弧、曲线、字符及组合图形的生成和显示。评价这类算法的核心指标是效率和稳定性。

#### 2.2 图形基础算法

主要包括：

- 矢量计算、矩阵运算、方程求解、插值等基础数学运算；
- 填充、相交、裁剪、曲线离散等图形算法；
- 长度、角度、距离、面积、质量等度量和物性计算；
- 平行、垂直、相交、干涉、包容等几何关系验证。

这些算法同样强调计算效率、结果可靠性和数值稳定性。

#### 2.3 参数化技术

参数化设计也称尺寸驱动设计。用户通过尺寸和几何约束定义图形，修改参数后系统自动更新相关图形，从而提高绘图和修改效率，并支持一定程度的自动绘图。

课件将参数化方法概括为三类：

1. 基于几何约束的数学方法；
2. 基于几何原理的人工智能方法；
3. 基于特征模型的造型方法。

参数化管理通常包含约束定义工具（共点、共线、平行、垂直、距离、角度等）、约束求解算法（约束分解、求解顺序规划、数值迭代和推理求解）以及变量表管理。

一个实用的参数化系统应能识别过约束和欠约束，可靠地求解约束，及时响应交互操作，允许修改约束，支持扩展新的约束类型，并适用于二维、三维模型和常规 CAD 数据。必要时还应允许人工干预。

#### 2.4 内存管理技术

图形系统需要处理内存分配、访问、碎片整理和大规模数据管理。重点是访问效率、避免内存泄漏以及维持长期运行的稳定性。开发工具选择和智能指针等技术会直接影响系统资源管理和运行性能。

#### 2.5 二次开发接口

二次开发接口通过提供通用调用函数，支持模块化开发，减少重复代码，并便于维护和扩展。接口设计应关注平台无关性、兼容性和可移植性；外部接口的稳定性通常比内部接口更难保证。

#### 2.6 通用图形库

通用图形库用于建立标准件库、常用零件库和用户自定义库。系统需要提供图形库的定义、添加、修改、删除和查询机制，通常结合数据库管理。典型内容包括螺栓、轴承、齿轮等标准件，以及面向汽车、飞机等行业的专用零件库。

### 3. 图形交互技术

#### 3.1 人机交互的作用

在 CAD/CG 系统中，用户输入设计意图，计算机负责计算、处理和显示，用户再根据反馈分析、修改并重新输入，形成“输入—反馈—修改”的循环。人机交互技术就是支撑这一循环的设备、软件和操作方法，是现代图形系统的重要组成部分。

交互设备从早期的键盘、显示器，逐渐发展到鼠标、图形输入设备以及语音、文字等模式识别设备，交互方式也从命令式逐步向图形化、自然化和智能化发展。

#### 3.2 物理输入设备

包括键盘、鼠标、跟踪球、操纵杆、数字化仪、触摸板、光笔、数据手套、扫描仪和数码相机等。

#### 3.3 逻辑输入设备

逻辑输入设备从功能角度描述输入，降低图形系统对具体硬件的依赖，提高独立性和灵活性，主要包括：

- 定位设备：输入一个位置坐标，例如鼠标；
- 笔划设备：连续输入一系列坐标；
- 字符串设备：输入字符，例如键盘、手写或语音识别；
- 定值设备：输入数值，例如标尺或刻度盘；
- 选择设备：从选项集合中选择元素；
- 拾取设备：拾取屏幕上的图形对象。

不同物理设备适合不同逻辑功能，例如鼠标和数字化仪适合定位，键盘适合输入字符串，光笔适合拾取图形。

### 4. 常用图形交互技术

- **对话框**：在确认前持续显示，允许用户从多个集合中选择，并输入、修改文本和数值，适合复杂参数输入。
- **橡皮筋技术**：确定起点后，随着光标移动实时显示临时线段、圆弧或矩形。其本质是反复执行“画—擦—移动—重画”的动态显示过程。
- **约束技术**：限制输入满足水平、垂直、平行、相切、长度或距离等条件；CAD 中的参数化设计是典型应用。
- **网格技术**：使输入点吸附到网格交点，帮助定位和绘制，可采用不同间距或局部网格。
- **引力场/捕捉（Snap）**：光标进入图元附近的吸附区域后，自动定位到端点、中点、切点、垂足等特征点。吸附范围需要在易用性和误吸附概率之间平衡。
- **拖动技术**：拾取对象后移动光标，对象跟随移动，底层同样需要动态擦除和重绘。
- **操作柄技术**：在对象周围显示操作柄，用于缩放、旋转、错切等变换。
- **Undo/Redo**：通过保存命令或操作序列，使用户可以撤销和恢复编辑操作，大型 CAD 软件通常支持多级甚至无限级撤销。
- **菜单技术**：通过主菜单、下拉菜单和弹出菜单组织命令，明确呈现可用选项并减少非法操作。

菜单设计应控制层级（一般不超过三层），将菜单放在不妨碍图形显示的位置；当选项较多时可采用分层或可移式菜单。

### 5. 图形用户界面设计原则

界面质量会影响软件的学习成本、操作效率、可靠性和产品化程度。界面设计需要综合考虑人的生理和心理特征。

屏幕设计关注布局、内容、字符、网格和颜色：

- 合理划分空间，突出重点并兼顾整体平衡；
- 选择易读的字体、字号、字形、对齐方式和间距；
- 合理使用颜色和亮度，避免光谱边缘色、红绿同时使用以及小字符使用蓝色，并用颜色区分信息类别、吸引注意力和减轻视觉疲劳。

基本设计原则包括：保持一致性、提供及时反馈、减少误操作、提供错误恢复、兼顾新手和熟练用户、减少用户记忆负担，以及提供随时可用的联机帮助。典型错误恢复方式有复原（Undo）、中止（Abort）、取消（Cancel）和校正（Correct）。

课件最后列举了 BCGControlBar、MFC、Qt 等 C++ 界面设计工具。

## 二、3.2-3 小型图形系统开发实践

### 1. 课程主线

本课以小型 CAD/图形系统为案例，分别介绍基于 MFC 的 VCAD、基于 OpenGL 的 Draw-OpenGL，以及基于 Qt 的 QCAD 框架。三者都围绕相同的 CAD 基本能力展开：图元创建、图元选择、图元编辑、视窗缩放、橡皮筋交互、文件操作和 Undo/Redo。

### 2. 基于 MFC 的 VCAD

#### 2.1 图元创建与数据组织

系统用全局图元链表 `CVCadDoc::m_EntityList` 保存模型中的全部实体。创建过程由用户输入命令对象（`CCommand`）驱动，并创建相应的实体对象（`CEntity`）及其派生类，体现“命令—实体”的对象组织方式。

#### 2.2 图元选择

选中的实体指针保存在实体选择集 `DOC::m_selectArray` 中。鼠标单击时通过实体包容盒判断候选对象，并根据正常、选中、拖动等状态使用不同显示模式。

#### 2.3 图元编辑

编辑命令同样从 `CCommand` 派生。典型编辑过程是变换关键点、将原实体标记为删除，再创建编辑后的新实体。这种方式把修改过程统一为命令操作，便于实现历史记录和撤销。

#### 2.4 视窗与坐标变换

系统支持 Zoom All/Extent、Zoom In、Zoom Out、Window 和 Pan 等视窗功能。模型坐标通过用户坐标系与屏幕坐标系之间的转换进行显示，主要参数包括坐标原点 `Xorg/YOrg` 和缩放比例 `scale`。缩放和平移只改变显示坐标系，不改变模型本身。

#### 2.5 橡皮筋、双缓存和文件

鼠标按下、移动、释放事件驱动橡皮筋和拖动操作。使用异或绘图模式（`R2_XOR`）可以通过再次绘制恢复背景，实现动态擦除和重画。

双缓存技术先在内存缓冲区绘制，再一次性复制到帧缓存，以避免图形闪动。文件功能涉及文档序列化、反序列化以及 CAD 文件的 DXF 转换。

#### 2.6 Undo/Redo

系统使用命令队列/堆栈（课件中记为 `CCommandQrue`）保存操作历史。显示实体时，每个实体只显示当前操作数下最大且未被标记删除的版本。Undo 使当前操作数减一，Redo 使其加一，从而恢复不同历史状态。

### 3. 基于 OpenGL 的 Draw-OpenGL

#### 3.1 交互函数与坐标转换

VCAD 的对象设计可以复用到 OpenGL 版本，只需在显示阶段用 OpenGL 函数替换 GDI 绘图函数。GLUT 提供鼠标、鼠标移动和键盘回调函数，例如 `glutMouseFunc`、`glutMotionFunc` 和 `glutKeyboardFunc`。

鼠标事件通常得到屏幕坐标，而图形实体使用世界坐标，因此交互绘图前必须完成屏幕坐标到世界坐标的转换。

#### 3.2 OpenGL 实体拾取

实体拾取采用 OpenGL 选择模式和名称栈：先设置选择缓冲区，进入 `GL_SELECT` 模式，初始化名称栈，为每个实体设置唯一名称，并通过 `gluPickMatrix` 定义光标附近的拾取窗口。调用 `glRenderMode(GL_RENDER)` 后得到命中数量和选择记录，再根据选择集处理被拾取的实体。

这一流程的关键步骤包括 `glSelectBuffer`、`glRenderMode`、`glInitNames`、`glPushName/glLoadName`、`gluPickMatrix` 和选择结果处理。

### 4. 基于 Qt 的 QCAD 框架

#### 4.1 图元创建与显示

图元存储在内存中，窗口刷新时重新显示模型，底层使用 `QPainter` 绘制。鼠标事件通过 `MCommand` 和 `MEntity` 体系传递，以直线等基本图元为例说明创建过程。

#### 4.2 选择与编辑

选择流程涉及 `QCADView::selectEntity()`、`MSelectCmd`、`QCADView::mousePressEvent()` 以及命令对象的 `OnLButtonDown`。编辑功能包括移动、旋转、镜像、删除和选择，对应 `moveEntity()`、`rotateEntity()`、`MirrorEntity()`、`eraseEntity()` 等方法及 `MMoveCmd` 等命令类。

#### 4.3 视窗缩放与坐标系

视窗使用 `m_Xorg`、`m_Yorg` 和 `m_scale` 描述坐标原点及缩放比例，支持 Zoom In、Zoom Out、Zoom All、Zoom Pan 和 Zoom Window 等操作，并通过坐标变换把模型坐标映射到窗口。

#### 4.4 橡皮筋、文件和 Undo/Redo

绘制直线、圆弧以及移动、旋转、镜像等编辑操作时，都可以使用橡皮筋效果。其原理是在 `MCommand::mouseMove()` 中动态改变图元坐标并不断刷新显示。

文件功能包括新建、打开、保存和另存为：打开时把文件读入内存并刷新显示，保存时把内存模型写回文件。Undo/Redo 则通过专门的数据存储结构保存和恢复操作状态。

### 5. 课件思考题与实践要求

课件要求熟悉 VCAD/QCAD 的体系结构和扩展方式，并提出两项上机练习：

1. 以多边形填充或剖面线为例，从交互简捷性、用户易用性、功能完整性和易学性等角度设计功能，并在现有 VCAD 系统上实现；
2. 使用 OpenGL 实现交互绘图和图元拾取。

## 三、两份课件的关联与总体理解

两份课件构成了从“理论与交互设计”到“系统实现”的连续内容：

| 理论/设计内容 | 工程实现对应 |
| --- | --- |
| 图元生成与基础几何算法 | `CEntity`/`MEntity` 图元对象及绘制函数 |
| 参数化、约束、捕捉 | 交互命令、坐标转换和约束输入 |
| 橡皮筋、拖动、操作柄 | 鼠标事件、异或绘图、动态刷新 |
| 图元选择与拾取 | 包容盒选择、OpenGL 选择模式 |
| 视窗缩放与平移 | 原点 `Xorg/Yorg`、缩放比例 `scale` |
| 错误恢复和历史操作 | 命令堆栈、Undo/Redo |
| 界面一致性与反馈 | MFC/Qt 界面、菜单、对话框和状态显示 |

总体而言，一个小型图形系统可以抽象为四层：

1. **数据层**：保存图元、实体属性和模型文件；
2. **几何与显示层**：完成坐标变换、图元绘制、缩放和平移；
3. **命令与交互层**：处理鼠标键盘事件、选择、编辑和橡皮筋反馈；
4. **界面与历史管理层**：提供菜单、对话框、文件操作及 Undo/Redo。

设计系统时既要关注算法和数据结构的正确性、效率与稳定性，也要关注反馈及时、操作可恢复、界面一致和学习成本低，这些因素共同决定图形软件的可用性。
