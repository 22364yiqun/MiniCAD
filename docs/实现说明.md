# 当前实现进度

## 1. 项目现状

项目采用独立的 C++ 程序完成直线操作和 Undo/Redo 验证，并使用 Qt 6 Widgets 提供主要二维界面。CMake 配置使用 C++20，并生成两个程序：

- `homework1`：命令行版直线编辑程序，源码为 `src/main.cpp`；
- `minicad_qt`：Qt AutoCAD 风格二维界面，源码为 `src/qt_main.cpp`。

## 2. 已实现功能

### 2.1 Qt MiniCAD 界面

`minicad_qt` 使用 `QMainWindow`、`QToolBar`、`QGraphicsView` 和 `QGraphicsScene`，已提供：

- 网格和 XY 坐标轴；
- Select、Line、Move、Rotate、Mirror、Delete 工具栏；
- 空白处两次点击创建直线；
- 选择并拖动直线移动；
- Rotate 工具拖动直线绕其中点旋转；
- Mirror 工具支持 X/Y 轴、两条对角线及自定义两点轴镜像；
- Delete 工具删除直线；
- 鼠标右键/中键平移，滚轮缩放；
- Undo/Redo 工具栏按钮及 `Ctrl+Z`/`Ctrl+Y` 快捷键。

### 2.2 命令行程序

`src/main.cpp` 已实现直线实体及以下五类操作：

- 创建：`create x1 y1 x2 y2`；
- 删除：`delete id`；
- 移动：`move id dx dy`；
- 旋转：`rotate id cx cy degrees`；
- 镜像：`mirror id ax ay bx by`。

程序还支持 `list`、`undo`、`redo`、`help`、`quit` 和 `exit` 命令。程序启动时会执行内置自测，覆盖创建、移动、旋转、镜像、删除、Undo、Redo、删除后恢复以及新操作清空 Redo 栈等情况。

## 3. Undo/Redo 的当前实现

命令行和 Qt GUI 共用 `src/version_history.h` 中的 `VersionHistory<Geometry>`，采用“操作数 + 双十字链表”方案，不再保存整份模型快照。

- **系统操作数**：`currentOperation_` 表示当前历史位置，初始为 0；Undo 递减，Redo 递增。
- **实体操作数**：版本节点的 `operation` 记录该实体版本产生的历史位置，`require(id).operation` 得到当前实体有效版本的操作数。
- **系统链**：节点通过 `systemPrev/systemNext` 按全局操作时间双向连接，`head_` 为链头，`cursor_` 指向当前历史位置。
- **实体链**：同一固定 ID 的版本通过 `entityPrev/entityNext` 双向连接，`entityTails_` 记录各实体的最新版本。
- **版本数据**：节点保存实体 ID、端点数据和删除标记。五类操作每次生成一个版本，删除不会立即丢弃可撤销的数据。

新操作先清理当前历史位置之后的 Redo 分支，再连接两条链并增加系统操作数。Undo/Redo 只移动系统链游标和操作数，不重新计算变换，也不重新创建实体。显示时从每个实体链尾向前查找操作数不超过系统操作数的最后一个版本；该版本有删除标记时不显示，不能跳过删除版本去显示旧版本。

实体 ID 单调分配且不回退，Undo 后创建新实体不会与已放弃的实体混淆。Redo 分支按系统链逆序回收，先修复实体链接和链尾，再用 `unique_ptr` 释放节点；若回收的是实体创建版本，同时移除对应的实体索引。模型销毁时容器自动释放剩余版本，四个链指针不拥有节点。

Qt 的 `lines` 仅保存当前显示数据及临时预览；拖动期间只保存被操作直线的起始状态，松开鼠标才写入一个版本。Undo/Redo 重新按操作数生成显示列表，并取消拖动、创建及自定义镜像等未完成交互，防止旧索引继续访问新列表。命令行保留五类命令对象，命令只负责计算并生成新版本，历史由公共核心管理。

`tests/history_tests.cpp` 使用独立快照作为测试参照，执行 4000 步多实体随机操作，并检查双向链链接、删除标记、空历史边界、连续 Undo/Redo、非法编辑和分支回收。`tests/qt_history_tests.cpp` 模拟鼠标交互和工具栏撤销重做，覆盖五类操作、两种镜像、预览不入历史及拖动中撤销。

## 5. 当前限制

- 没有接入真实 QCAD/MFC 工程；
- 没有文件保存、加载和 DXF 转换；
- 没有多实体框选和捕捉；已有单实体选择和直线绘制预览；
- 命令行程序只管理直线，不支持圆弧、多边形等其他图元；
- Qt 界面尚不是完整 CAD 编辑器；

## 6. Qt 构建

Qt 6.8.3 已安装到项目目录 `qt/6.8.3/mingw_64`。由于该 Qt SDK 使用 MinGW 13.1 构建，CMake 需要使用 CLion 自带的同版本 MinGW：

```powershell
cmake -S . -B cmake-build-qt-jb -G Ninja `
  "-DCMAKE_PREFIX_PATH=$PWD/qt/6.8.3/mingw_64" `
  "-DCMAKE_C_COMPILER=D:/JetBrains/CLion 2025.2.4/bin/mingw/bin/gcc.exe" `
  "-DCMAKE_CXX_COMPILER=D:/JetBrains/CLion 2025.2.4/bin/mingw/bin/g++.exe"
cmake --build cmake-build-qt-jb --target minicad_qt
```

生成的 Qt 程序为 `cmake-build-qt-jb/minicad_qt.exe`，运行所需 Qt DLL 已部署到同一目录。

构建及运行全部测试（需将 Qt 和 MinGW 的 `bin` 加入当前终端的 `PATH`）：

```powershell
cmake --build cmake-build-qt-jb
ctest --test-dir cmake-build-qt-jb --output-on-failure
```
