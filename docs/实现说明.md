# 当前实现说明

目录中原本没有 QCAD 工程源码，因此本次实现提供了一个独立的 C++17 最小程序，文件为 `src/main.cpp`。它严格覆盖 `readme.md` 的要求：

- 直线创建；
- 直线删除；
- 直线平移；
- 直线旋转；
- 直线镜像；
- Undo/Redo；
- 删除后可撤销恢复；
- 新操作自动清空 Redo 栈；
- 使用 `unique_ptr` 管理命令对象，模型和历史销毁时自动释放内存。

## 运行方式

需要 CMake 3.16 以上和 C++17 编译器：

```powershell
cmake -S . -B build
cmake --build build --config Debug
.\build\line_undo_redo.exe
```

程序启动时会先运行一组自测。看到 `self-test passed` 表示创建、移动、旋转、镜像、删除、Undo、Redo 和 Redo 栈清空测试通过。

交互命令示例：

```text
create 0 0 100 0
move 1 10 20
rotate 1 0 0 90
mirror 1 0 0 0 1
delete 1
undo
redo
list
quit
```

## 实现结构

- `LineEntity`：保存直线 id、两个端点和删除标记；
- `LineModel`：保存全部实体，负责创建、查找、快照和恢复；
- `CreateLineCommand`、`DeleteLineCommand`、`MoveLineCommand`、`RotateLineCommand`、`MirrorLineCommand`：对应五种操作；
- `StateCommand`：保存命令执行前后的完整模型状态，统一实现 Undo/Redo；
- `History`：维护 Undo 栈和 Redo 栈。

删除采用逻辑删除：实体保留在模型快照中，只是不再显示。只有命令历史销毁后，相关状态由 C++ 容器自动释放，这样 Undo 不会访问悬空指针。

如果之后拿到老师提供的 QCAD 工程，可以把这些命令的核心逻辑迁移到其 `MCommand`/`MEntity` 派生类中；当前目录没有该工程，因此无法直接修改 QCAD 的窗口和鼠标界面。
