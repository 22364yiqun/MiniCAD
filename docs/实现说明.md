# 当前实现进度

## 1. 项目现状

项目采用独立的 C++ 程序完成直线操作和 Undo/Redo 验证。CMake 配置使用 C++20，并生成两个程序：

- `homework1`：命令行版直线编辑程序，源码为 `src/main.cpp`；
- `homework1_viewer`：Windows/OpenGL 交互查看器，源码为 `src/viewer.cpp`。

## 2. 已实现功能

### 2.1 命令行程序

`src/main.cpp` 已实现直线实体及以下五类操作：

- 创建：`create x1 y1 x2 y2`；
- 删除：`delete id`；
- 移动：`move id dx dy`；
- 旋转：`rotate id cx cy degrees`；
- 镜像：`mirror id ax ay bx by`。

程序还支持 `list`、`undo`、`redo`、`help`、`quit` 和 `exit` 命令。程序启动时会执行内置自测，覆盖创建、移动、旋转、镜像、删除、Undo、Redo、删除后恢复以及新操作清空 Redo 栈等情况。

### 2.2 Windows/OpenGL 二维查看器

`src/viewer.cpp` 已实现一个独立的交互窗口：

- 鼠标左键连续点击创建 XY 平面上的直线；
- 按住鼠标左键拖动已有直线可以移动直线；
- 按住 `Shift` 再用鼠标左键拖动已有直线可以绕直线中点旋转；
- 鼠标右键或中键拖动平移二维视图；
- 鼠标中键拖动平移视图；
- 鼠标滚轮缩放；
- 显示网格和 XYZ 坐标轴；
- `Ctrl+Z` 撤销创建或拖动操作，`Ctrl+Y` 重做；
- `Esc` 取消尚未完成的起点输入。

当前查看器主要用于交互绘制和视图操作，尚未接入命令行程序的完整五类编辑命令。

## 3. Undo/Redo 的当前实现

命令行程序采用“命令对象 + 前后状态快照”方案：

- `Command`：定义命令接口；
- `CreateLineCommand`、`DeleteLineCommand`、`MoveLineCommand`、`RotateLineCommand`、`MirrorLineCommand`：分别实现五类操作；
- `StateCommand`：在命令执行前后保存完整模型状态；
- `History`：维护 Undo 栈和 Redo 栈。

执行新命令时，命令进入 Undo 栈并清空 Redo 栈。Undo 将命令移到 Redo 栈并恢复执行前状态；Redo 将命令移回 Undo 栈并恢复执行后状态。

删除采用逻辑删除，实体仍保留在模型状态中，因此删除后可以可靠地 Undo。命令对象使用 `unique_ptr` 管理，模型和历史销毁时由 C++ 容器自动释放相关内存。

## 5. 当前限制

- 没有接入真实 QCAD/MFC/Qt 工程；
- 没有文件保存、加载和 DXF 转换；
- 没有实体选择、框选、捕捉和橡皮筋正式预览；
- 命令行程序只管理直线，不支持圆弧、多边形等其他图元；
- OpenGL 查看器是二维 XY 平面绘制窗口，尚不是完整 CAD 编辑器；
- 操作数和双十字链表方案尚未落地。
