# 当前实现进度

## 1. 项目现状

项目将直线模型、五种操作命令与 Undo/Redo 历史放在 `src/line_model.hpp`。Qt 6 Widgets 界面的鼠标操作与窗口内文本命令共用这一套核心。CMake 使用 C++20，生成 `minicad_qt` 可视化程序；不再生成独立命令行程序。

## 2. 已实现功能

### 2.1 Qt MiniCAD 界面

`minicad_qt` 使用 `QMainWindow`、`QToolBar`、`QGraphicsView` 和 `QGraphicsScene`，已提供：

- 网格和 XY 坐标轴；
- Select、Line、Move、Rotate、Mirror、Delete 工具栏；
- 空白处两次点击创建直线；
- 选择并拖动直线移动；
- Rotate 工具依次单击直线、单击任意旋转中心，再从中心以外按住鼠标拖动以确定角度；
- Mirror 工具关于水平轴镜像；
- Delete 工具删除直线；
- 鼠标右键/中键平移，滚轮缩放；
- Undo/Redo 工具栏按钮及 `Ctrl+Z`/`Ctrl+Y` 快捷键。

### 2.2 窗口内命令输入

Qt 窗口底部输入框直接操作当前画布，支持：

- 创建：`create x1 y1 x2 y2`；
- 删除：`delete id`；
- 移动：`move id dx dy`；
- 旋转：`rotate id cx cy degrees`；
- 镜像：`mirror id ax ay bx by`。

输入框还支持 `list`、`undo`、`redo` 和 `help`。`tests/qt_history_test.cpp` 覆盖鼠标与文本命令、五种操作、Undo/Redo、自定义镜像轴以及新操作清空 Redo。

## 3. Undo/Redo 的当前实现

Qt 界面的鼠标操作和文本命令共用“命令对象 + 前后状态快照”方案：

- `Command`：定义命令接口；
- `CreateLineCommand`、`DeleteLineCommand`、`MoveLineCommand`、`RotateLineCommand`、`MirrorLineCommand`：分别实现五类操作；
- `StateCommand`：在命令执行前后保存完整模型状态；
- `History`：维护 Undo 栈和 Redo 栈。

Qt 界面在鼠标操作确认后提交相应命令；拖动期间只显示预览。执行新命令时，命令进入 Undo 栈并清空 Redo 栈。Undo 将命令移到 Redo 栈并恢复执行前状态；Redo 将命令移回 Undo 栈并恢复执行后状态。

删除采用逻辑删除，实体仍保留在模型状态中，因此删除后可以可靠地 Undo。命令对象使用 `unique_ptr` 管理，模型和历史销毁时由 C++ 容器自动释放相关内存。

## 4. 与作业要求的对应关系

| 作业要求 | 当前状态 |
| --- | --- |
| 参考类设计实现直线操作 | 鼠标操作与文本命令共用 `Command`/`LineEntity` 结构 |
| 创建、删除、移动、旋转、镜像 | Qt 鼠标操作与窗口内命令均已完成 |
| Undo/Redo | Qt 工具栏与窗口内命令均已完成 |
| 内存释放 | 已使用容器和 `unique_ptr` 管理当前实现中的对象 |
| 实体操作数、系统操作数 | 尚未实现 |
| 双十字链表 | 尚未实现 |

当前程序使用命令快照方案；“操作数 + 双十字链表”尚未实现。如果最终采用该方案，还需要增加系统操作链、实体版本链、实体操作数、系统操作数和对应的版本回收策略。

## 5. 当前限制

- 没有接入真实 QCAD/MFC 工程；
- 没有文件保存、加载和 DXF 转换；
- 已有单条直线点选和画线橡皮筋预览；尚无框选和捕捉；
- 当前模型只管理直线，不支持圆弧、多边形等其他图元；
- Qt 界面尚不是完整 CAD 编辑器；
- 操作数和双十字链表方案尚未落地。

## 6. Qt 构建

Qt 6.8.3 已安装到项目目录 `qt/6.8.3/mingw_64`。VS Code 的 `vscode-debug` 预设已配置匹配的 MinGW 13.1 工具链：

```powershell
$cmake = './qt/Tools/CMake_64/bin/cmake.exe'
& $cmake --preset vscode-debug
& $cmake --build --preset vscode-debug --target minicad_qt
```

生成的 Qt 程序为 `cmake-build-vscode/minicad_qt.exe`，运行所需 Qt DLL 已部署到同一目录。
